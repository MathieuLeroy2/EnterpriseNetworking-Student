# Ch6 workshop configs

Deze map bevat ondersteunende bestanden voor workshop 6.

De Ch6-workshop gebruikt student-managed persoonlijke tailnets.

Elke student beheert dus de eigen Tailscale-policy.

Studenten gebruiken alleen de bestanden in `student/`.

Docenten gebruiken de bestanden in `teacher/`.

Veiligheidsregel:

> Neem geen auth keys, loginlinks, tokens, recovery codes of wachtwoorden op in verslagen of gedeelde bestanden.
